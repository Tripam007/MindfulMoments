# 🌱 Mindful Moments

**Mindful Moments** is a privacy-first, AI-powered wellness application designed to help students build emotional awareness through journaling, mood trend tracking, and gentle proactive support — without diagnosis or stigma.

## 🧠 Problem Statement

Students face increasing academic and social pressure, yet many hesitate to seek help due to stigma, lack of awareness, or delayed self-realization. Most mental health solutions are reactive and rely on users actively asking for support.

Mindful Moments addresses this gap by helping students **recognize emotional patterns early**, enabling awareness and support before distress escalates.

---

## 💡 Solution Overview

Mindful Moments provides a secure space for students to:
- Privately journal their thoughts
- Automatically generate mood scores using AI-based sentiment logic
- Track emotional trends over time
- Receive gentle, non-intrusive support suggestions when persistent negative patterns are detected

⚠️ This application is **not a medical or diagnostic tool**. It is designed strictly for wellness support and emotional awareness.

---

## ✨ Key Features

### 🔐 Secure Authentication
- Email and password-based login
- User-specific, isolated data access

### 📝 Journaling
- Text-based daily journal entries
- Timestamped and securely stored

### 🤖 Mood Analysis
- Lightweight sentiment analysis
- Journal entries converted into a **mood score (1–10)**
- Focus on trends rather than single emotional states

### 📊 Mood Trend Tracking
- Time-series tracking of mood scores
- Identification of prolonged low or declining trends

### 💬 Proactive Support
- Gentle, optional support prompts when negative trends persist
- Encourages wellness resources without alarms or labels

### 🛡️ Privacy & Ethics
- No diagnosis or clinical claims
- Privacy-first data handling
- Transparent disclaimers and opt-in interactions

## 🏗️ Tech Stack

### Frontend
- React / Next.js
- Firebase Authentication
- Firebase Firestore

### Backend
- Node.js (logic & processing)
- Trend detection and sentiment scoring

### Security
- Environment variables for sensitive configuration
- Firestore security rules for user data isolation

---

## 🔄 Application Flow

1. User signs up or logs in
2. Writes a journal entry
3. Entry is analyzed for sentiment
4. Mood score is generated and stored
5. Mood trends are evaluated over time
6. Support suggestions appear if needed
